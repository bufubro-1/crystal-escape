# CMPE 411 Testing Plan

I will test Crystal Escape, a turn-based 8 × 8 browser game in which a player collects three crystals, avoids hazards, and reaches the exit within 40 turns. I will use the Node.js test runner for unit tests of movement, scoring, health, and win and loss rules, and Playwright with Chromium for browser end-to-end tests of keyboard controls, visible counters, restart, and game outcomes. I will trace at least 20 automated cases to written requirements using equivalence partitioning, boundary value analysis, and state transition testing, and run both levels with `npm test`. A seeded bot will generate repeatable telemetry across six fixed maps. I will fit a five-nearest-neighbor detector and a maximum standardized deviation baseline on normal runs, set each alert threshold at the 95th percentile of scores on separate normal calibration runs, and compare detections, misses, and false alarms on the same held-out normal runs and labeled synthetic alterations.
